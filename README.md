# AI-Driven-Multimodal-Healthcare-System
An AI-driven IoT healthcare system for remote patient care. An ESP32 monitors ECG, BPM, SpO₂, and body temperature, transmitting live vitals to doctors via Blynk. The setup includes an ESP32-CAM video feed, automated medication alerts, and an AI voice assistant linked to a NodeMCU for home automation, supporting post-intensive care at home.
